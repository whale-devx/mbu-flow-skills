# Test strategy

## Coverage map
Map requirements to unit, contract, integration, end-to-end and risk-driven security/performance tests.

## Isolation
Each unit must build and test against baseline fixtures without another unit's unfinished code.

## Evidence
Record exact command, environment, commit, exit code and artifact location. Never infer a pass.

## Limitations
State which providers, platforms and external integrations have not been exercised.
