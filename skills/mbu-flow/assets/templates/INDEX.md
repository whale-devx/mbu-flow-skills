# Project knowledge index

## Current source of truth
List existing product, design, delivery and decision documents using relative Markdown links.
Do not add links to documents that do not exist. Reuse the repository's existing locations.

## Ownership
Git owns reviewed documents and contract baselines. The issue tracker owns live ticket status.
The execution service, when implemented, owns run state. Do not copy live state into editable tables.

## Retrieval
Read the relevant requirement, unit and contracts, not the entire vault. Record verified findings only.
Opening this directory as an Obsidian vault is optional; no plugin is required.
